### Описание ключевых решений


## Ключевые решения для Task4

### 1. **osago-aggregator**

| Аспект               | Решение                                          |
|----------------------|--------------------------------------------------|
| **Хранилище**        | PostgreSQL / Redis для хранения состояний заявок |
| **API для core-app** | REST (POST /api/osago/apply)                     |
| **Интеграция**       | REST + Kafka (асинхронная обработка)             |
| **Масштабирование**  | Горизонтальное (несколько реплик)                |


### 2. **Интеграция веб-приложения**


| Аспект                  | Решение                                            |
|-------------------------|----------------------------------------------------|
| **Средство интеграции** | WebSocket / SSE                                    |
| **Причина**             | Потоковая передача предложений по мере поступления |
| **Отличие от REST**     | Асинхронная, двусторонняя связь                    |


### 3. **Паттерны отказоустойчивости**


| Паттерн             | Где применяется                             | Цель                            |
|---------------------|---------------------------------------------|---------------------------------|
| **Rate Limiting**   | API Gateway                                 | Защита от перегрузок            |
| **Circuit Breaker** | core-app → osago-aggregator                 | Защита при недоступности        |
| **Circuit Breaker** | osago-aggregator → страховые компании       | Защита от недоступных API       |
| **Retry**           | osago-aggregator → страховые компании       | Повтор при временных сбоях      |
| **Timeout**         | osago-aggregator → страховые компании (60с) | Соответствие бизнес-требованиям |
