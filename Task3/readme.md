# Задание 3. Переход на Event-Driven архитектуру

## Основные решения
1. **Event-Driven** — замена синхронных REST-вызовов на асинхронные через Message Broker
2. **Transactional Outbox** — гарантированная доставка событий
3. **CQRS** — разделение команд и запросов
4. **Rate Limiter** — ограничение 20 RPS для B2B
5. **Health Checks** — повышение отказоустойчивости
